
# Home Server Backup

Home Server Backup is a personal, non-commercial backup utility for a privately operated home server.

## What it does

The application uses rclone and Google Drive to securely store encrypted backup archives of personal services, including Nextcloud and n8n.

It performs scheduled backups, verifies backup integrity, and manages backup retention.

## Google Drive access

Google Drive access is used only to upload, read, verify, and manage backup files owned by the application operator.

The application is intended for personal use and is not offered as a public service.
