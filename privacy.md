# Privacy Policy — Home Server Backup

**Last updated: October 11, 2026**

## 1. Overview

Home Server Backup is a personal, non-commercial application used to securely back up data from a privately operated home server to Google Drive.

The application is operated for personal use and is not offered as a public service.

## 2. Data Access

The application uses Google Drive API access to upload, read, verify, and manage backup files.

Access is used only for backup-related operations authorized by the Google account owner.

## 3. Data Storage and Security

Backup archives are encrypted before being uploaded to Google Drive.

Encryption passwords and access credentials are stored privately and are not published on this website.

## 4. Data Sharing

The application does not sell personal information, use Google user data for advertising, or disclose backup contents to advertisers.

Google Drive is used as the cloud storage provider.

## 5. Data Retention

The backup system is configured to retain local backups for approximately 7 days and cloud backups for approximately 30 days.

The application operator can manually delete backup files or revoke Google Drive access.

## 6. Third-Party Services

The application uses Google Drive for backup storage and rclone for file transfers.

This public information website is hosted by GitHub Pages and is subject to GitHub's own privacy practices.

## 7. Contact

Questions about this application or its privacy practices can be directed to the user support email listed on its Google OAuth consent screen.

## 8. Changes

This privacy policy may be updated if the application's functionality or data-handling practices change.
